**Help for Job (HfJ)** — это умный и безопасный помощник для Arizona RP Mobile, который автоматизирует рутину на работах (такси, дальнобойщик, инкассатор) и ведёт точный учёт зарплаты. Скрипт написан для MoonLoader/MonetLoader с использованием современного интерфейса `mimgui`.

---

## 🆕 Что нового в v29.0.3
- **Турбо-ловля (0 мс):** Добавлен переключатель мгновенной ловли заказов в настройках автоловли для максимальной конкурентоспособности против других инструментов.
- **Предупреждения безопасности:** Интегрированы предупреждения в интерфейсе о рисках использования турбо-режима без задержки.
- **Расширенная система логирования:** В папку `logs` добавлен детальный лог `hfj.log` с миллисекундной точностью, автоочисткой при реконнекте/входе в игру и разделением событий (`ACT`, `DLG`, `CHAT`, `ERROR`).
- **Исправления стабильности:** Улучшено управление состоянием заказа, устранены ложные срабатывания при старте работы и исправлено закрытие диалогов на мобильном лаунчере (MonetLoader).

## ✨ Основные возможности

- 🎯 **Автоловля заказов:** Быстрый перехват заказов с возможностью выбора между безопасным случайным задержками (40–90 мс) и турбо-режимом (0 мс).
- 🛡️ **Безопасность превыше всего:** Скрипт **никогда** не нажимает автоматически на платёжные окна (диалоги с `:CASH:` или «Вознаграждение»), защищая ваши средства.
- 💰 **Учёт зарплаты (ЗП):** Раздельные счётчики для Такси, Дальнобойщика и Инкассатора.
- 📏 **Защита от фейков:** Выплата засчитывается в статистику только после реального проезда 50+ метров.
- 🎨 **Стильный UI:** Тёмное стеклянное меню с плавными анимациями, тумблерами и стильными всплывающими уведомлениями.
- 🔄 **Автообновление:** Встроенная проверка новых версий прямо с GitHub и установка в один клик.
- 💾 **Сохранение прогресса:** Вся статистика и настройки (включая турбо-режим) сохраняются в конфиг.

## 📥 Установка

1. Убедитесь, что у вас установлен **MoonLoader** (или **MonetLoader**) и библиотека **mimgui**.
2. Скачайте файл `Help_for_Job.lua` из раздела [Releases](https://github.com/hshajqk710-glitch/taxord/releases).
3. Поместите файл в папку `moonloader` на вашем устройстве.
4. Зайдите в игру. Скрипт автоматически создаст папки `config` и `logs` для сохранений.
5. Введите в чат `/hfj`, чтобы открыть меню.

## 💻 Команды

Управлять скриптом можно как через удобное меню, так и через чат:

| Команда | Описание |
| :--- | :--- |
| `/hfj` | Открыть или закрыть главное меню скрипта |
| `/taxord` | Старый алиас для вызова меню (совместимость) |
| `/zarabotok` | Показать подробную статистику заработка в окне |
| `/resetstat` | Полный сброс статистики заказов и зарплаты |
| `/checkupd` | Проверить наличие обновлений на GitHub |
| `/update` | Принудительно скачать и установить обновление |
| `/updinfo` | Диагностика апдейтера (версии, транспорты, статус) |
