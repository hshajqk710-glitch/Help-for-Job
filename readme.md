**Help for Job (HfJ)** — это умный и безопасный скрипт-помощник для серверов Arizona RP Mobile. Он автоматизирует рутину на ключевых работах (такси, дальнобойщик, инкассатор), исключает случайные траты виртов и ведёт раздельный прозрачный учёт заработка с защитой от накрутки.

Скрипт оптимизирован для работы в средах **MonetLoader** и **MoonLoader** с использованием современного графического движка **mimgui**.

---

## 🆕 Что нового в v29.0.4

- 🛡️ **Защита от дублей заказов:** Устранён перехват повторных диалогов при быстром потоке серверных пакетов.
- 🏦 **Разблокировка банковских меню:** Исправлен конфликт с диалогом основного счета и налогами (`id=6565`). Теперь сервисные диалоги с кнопкой «Принять» не перехватываются скриптом.
- ⚡ **Оптимизация сканера тапов:** Сокращено количество холостых сетевых пакетов (`MAX_TAPS = 12`, интервал `70 мс`), полностью исключены зависания очереди поиска заказов.
- ⏱️ **Естественная задержка реакции:** Ответ на диалоги в стандартном режиме отправляется с динамической паузой 180–320 мс, имитируя живой клик игрока по экрану.
- 🎨 **Обновление интерфейса:** Вкладки сайдбара переименованы в «Такси» и «Счетчик ЗП», убран лишний визуальный шум в шапке окна.

## ✨ Основные возможности

- 🎯 **Умная автоловля вызовов:** Быстрый перехват заказов такси через чат и серверные диалоги с безопасными задержками или опциональным турбо-режимом (0 мс).
- 🔒 **Защита баланса (Анти-слив):** Скрипт игнорирует любые диалоговые окна с комиссиями, оплатой налогов и тегом `:CASH:`.
- 💰 **Раздельный счётчик ЗП:** Точная фиксация заработка для трёх основных профессий: Такси, Дальнобойщик и Инкассатор.
- 📏 **Валидация по дистанции:** Зарплата начисляется в статистику только при условии реального движения транспорта (более 50 метров).
- 🖥️ **Современный Glass-дизайн:** Тёмное меню с анимацией переходов, плавными тумблерами и всплывающими тост-уведомлениями.
- 🔄 **Встроенный автоапдейтер:** Проверка обновлений и загрузка актуальной версии прямо во время игровой сессии.

## 📥 Установка

1. Убедитесь, что у вас установлен **MonetLoader** (или **MoonLoader**).
2. Скачайте файл `Help_for_Job.lua` из раздела [Releases](https://github.com/hshajqk710-glitch/Help-for-Job/releases).
3. Поместите скачанный файл в папку `moonloader` вашего лаунчера.
4. Запустите игру. При первом старте скрипт автоматически создаст рабочие директории `config` и `logs`.
5. Введите команду `/hfj` в игровой чат для открытия интерфейса.

## 💻 Список команд

| Команда | Описание |
| :--- | :--- |
| `/hfj` | Открыть / закрыть главное меню управления |
| `/taxord` | Дополнительный алиас для открытия меню |
| `/zarabotok` | Вывести подробный отчёт заработка по профессиям в диалоговом окне |
| `/resetstat` | Сбросить накопленную статистику заказов и выплат |
| `/checkupd` | Запустить ручную проверку наличия обновлений |
| `/update` | Принудительно загрузить и применить обновление |
| `/updinfo` | Показать системную информацию о модуле обновления |
