HELP FOR JOB

Умный скрипт для автоматизации заказов и прозрачного учета заработка на мобильных серверах.

Автоловля заказов

Перехватывает заказы через диалоги и чат с естественными задержками клика без риска для аккаунта.

💰

Счётчик зарплаты

Раздельный учет для Такси, Дальнобойщиков и Инкассаторов с валидацией через пройденную дистанцию.

🛡️

Защита баланса

Полная блокировка случайных оплат — скрипт игнорирует любые всплывающие окна с комиссиями и :CASH:.

🔄

OTA Обновления

Проверка релизов напрямую с GitHub и обновление скрипта прямо во время игры в один тап.
